# 数字分量化细则（scale-rubric）

> 配套 `deflavor` skill。分数方向：越高 = AI 味越重，0 = 最干净。
> 硬指标由 `scripts/score.py` 自动扫描（封顶 70），软指标由模型评估（封顶 30），合计封顶 100。

---

## 一、硬指标权重表（封顶 70）

| 扫描项 | 权重/处 | 说明 | 来源 |
|--------|---------|------|------|
| 通用塑料黑话 | **+3** | 赋能/重塑/杠杆/底层/维度（含"底层逻辑"等变形） | 通用强化项 |
| humanizer 一级禁用词 | +2 | 仿佛/犹如/一丝/一抹/微微/轻轻/淡淡/眼中闪过/嘴角勾起/眉头微皱/心中一动/心头一震/不容置疑/显而易见/毫无疑问/坚定/深邃/凛冽… | humanizer banned-words |
| humanizer 二级禁用词 | +2 | 突然/好像/瞬间（高频或偷懒时）等 | humanizer banned-words |
| 标点违规 | **+3** | 冒号 `：`/`:`、破折号 `——`、中文双引号 `""` | 通用标点禁令 |
| "不是A而是B"毒句式 | **+5** | 假靶子/同义替换/无关硬凑/NNY 变体；**好用法不计** | humanizer 三毒机制 |
| 高频堆叠副词 | +1 | 极其/极度/猛地/死死/狠狠/稳稳/瞬间/紧接着… | humanizer v4.0 |
| 连接词套话 | +1 | 此外/值得注意的是/综上所述/首先其次最后/一方面另一方面/毋庸置疑/随着…发展/在…背景下… | humanizer 连接词 |
| 科普起手式 | +3 | 先说答案/掰开了揉碎了/拆解/你品一下/看明白了吗 | humanizer v4.0 |
| 自问自答老师腔 | +2 | 这叫什么？/说明什么？/怎么办到的？ | humanizer v4.0 |
| "你以为A实际上B" | +3 | 先假装读者有错，再显摆 | humanizer v4.0 |
| 陈词滥调比喻 | +3 | 如沐春风/梨花带雨/命运的齿轮/精准的手术刀/如潮水般 | humanizer 比喻表 |

**"不是A而是B"判定（关键）**
- 毒1 假靶子：前半句否定一个根本没人做过的判断 → 计分
- 毒2 同义替换：A 与 B 同一意思 → 计分
- 毒3 无关硬凑：不需转折处强行"不是而是" → 计分
- **好用法**：真有人会做该判断且 A≠B（如"爱的不是容貌而是灵魂"）→ **不计分**

## 二、软指标评估（封顶 30，由模型判）

| 维度 | 缺陷 | 加分 |
|------|------|------|
| L2 口语化 | 全文偏书面、没用任何口语化词组、无"我"/无自嘲 | +3~8（按程度） |
| L2 节奏 | 句长一致、无长短交错、无单句成段断裂 | +3~8 |
| L3 观点支撑 | 核心观点无具体人/数据/场景支撑 | +5 |
| L3 知识输出 | 知识点以"下面我来科普"姿态呈现 | +5 |
| L4 温度感 | 情绪是知识性描述而非体感记忆 | +5 |
| L4 独特性 | 没有"只有这个作者才写得出的角度" | +5 |
| L4 姿态 | 滑向"导师教学生"而非"有见识的普通人聊" | +5 |
| L4 心流 | 读时注意力断掉、需回头理解逻辑 | +5 |

## 三、等级映射（默认门槛，可按场景调整）

| 分数段 | 等级 | 处置 |
|--------|------|------|
| 0–22 | 优 | 可直接发（≤22 优线） |
| 23–29 | 合格 | <30 门槛内，偏临界，建议再磨一句 |
| 30–50 | 中度 | 返工到 <30 再发 |
| 51–100 | 重度 | 必须重写 |

> 默认门槛：目标 **0 分**，硬性 **<30** 才可发布，优 **≤22**。这是通用建议值，可按账号调性调整。
